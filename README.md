# SPACE RESCUE — 백데렐라 구출 작전

브라우저에서 실행하는 2D 우주 중력 시뮬레이션 게임입니다.

## 실행
GitHub 저장소 Settings → Pages → Deploy from a branch → `main` / `/(root)`를 선택하면 웹에서 실행할 수 있습니다. 또는 index.html을 브라우저에서 엽니다.

## 구현 기능
- Canvas 기반 우주 배경 및 반응형 UI
- 1~10레벨 천체 배치, 중력에 따른 우주선 운동과 예상 궤도
- 속도·방향 미세 조절, X/Y 기울기 및 Z축 회전 UI
- 0.25× / 0.5× / 1× / 2× 배속
- PC 우클릭 및 모바일 길게 누르기로 천체 정보 확인
- 웜홀 도달, 레벨 클리어, 충돌 패배 처리
- 11레벨 전투 점수와 구출 엔딩
- LocalStorage 기반 랭킹, JSON 백업/복원
- CSV, Excel 호환 XLS, JSON, TXT, HTML 내보내기

## 데이터 보존
서버와 데이터베이스를 사용하지 않습니다. 랭킹은 플레이한 브라우저의 LocalStorage에 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서는 기록이 공유되지 않으므로 축제 운영 전후 JSON 백업을 권장합니다. XLSX 메뉴는 외부 라이브러리 없이 Excel 호환 HTML 스프레드시트(.xls)를 내보냅니다.

## 물리 모델 범위
중력은 뉴턴식 근사 모델이며 안정화를 위해 중력 소프트닝과 가속도 상한을 사용합니다. 일부 천체는 플레이성을 위해 설정된 궤도로 움직입니다. 블랙홀 렌즈 효과와 웜홀은 과학 개념에서 영감을 받은 시각 효과이며, 일반상대성이론의 완전한 광선 추적이나 실제 웜홀 해법은 아닙니다.

## 후속 개선 권장
- 계층형 N-body 공전 통합 및 수치 검증
- 예측 궤도와 실제 적분기의 오차 테스트
- 터치 기반 카메라 이동/확대
- UFO 추적·발사체 충돌과 소행성 충돌 구현
- 전투 점수를 실제 명중 판정과 연동
- 정식 XLSX 생성 및 자동 백업
